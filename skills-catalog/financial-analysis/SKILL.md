# Financial analysis skill

Use this skill for stock, company, ETF, fund, earnings, or filing questions.

## Workflow

1. Confirm the ticker / company and market (US vs India).
2. Pull recent filings / earnings context from public sources.
3. Note thesis, risks, and red flags.
4. Deliver a short chat summary; write long memos to `artifacts/<ticker>-report.md` and `/opt/cursor/artifacts/<ticker>-report.md`.

## Output

- Short asks → answer in chat only.
- Full research → markdown report + 1–2 sentence Slack summary.
- PDF only if the user explicitly asks.
